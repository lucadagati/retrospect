\begin{abstract}
The convergence of cloud-native orchestration and embedded runtime execution is a key challenge in cyber-physical systems, especially when secure and remotely managed application lifecycles are required across heterogeneous devices. Existing cloud orchestrators expose rich declarative control and observability primitives, but they assume host capabilities, network semantics, and runtime abstractions that are not directly available on constrained embedded targets. Conversely, embedded deployment pipelines often privilege device-specific feasibility over fleet-wide control, reproducibility, and life-cycle accountability. This mismatch leaves a practical gap between cloud intent and verifiable edge execution.

This paper presents RETROSPECT, a Kubernetes-native Cloud--Fog--Edge platform designed to deploy and supervise WebAssembly (WASM) workloads on embedded-class targets through a gateway-centric architecture. RETROSPECT combines Custom Resource Definitions (CRDs), Rust-based control services, Transport Layer Security (TLS) southbound communication, and compact CBOR messaging to enable device enrollment, secure attachment, heartbeat-driven liveness supervision, and runtime control of edge applications. The platform integrates Zephyr-based firmware and WAMR execution for constrained targets, and it supports emulation-driven validation using Renode in order to make development and experimentation reproducible before moving to physical hardware.

The main contribution is a complete systems design and implementation that links declarative cloud intent to edge execution state under a unified control plane. We detail the architecture, control semantics, protocol workflow, implementation decisions, reconciliation logic, and deployment methodology, and we report end-to-end validation outcomes from a real K3s-based deployment workflow. The reported study is intentionally system-centric: rather than isolating a single runtime optimization, it demonstrates that secure enrollment, liveness supervision, and application life-cycle coordination can be achieved consistently in a constrained edge setting when the ownership of state transitions is made explicit and when runtime-observable evidence is separated from eventual-consistency artifacts in the control plane.

The final 50-trial campaign reports a success rate of 1.0 for enrollment, heartbeat supervision, deployment, and full transactional completion. Wilson score intervals at 95\% confidence yield a lower bound of 92.9\%. Mean latencies are 539.5~ms for enrollment, 3.90~ms for heartbeat observability, 521.0~ms for deployment, and 1.06~s end-to-end ($t_{0.975,\,49}=2.010$, CI [1022.8, 1098.2]~ms). In addition to mean and confidence interval reporting, the evaluation includes Wilson intervals for binary outcomes, percentile-based latency analysis, coefficient of variation, empirical CDF, per-trial stationarity scatter, and per-stage goodput. Beyond the specific prototype, RETROSPECT demonstrates that cloud-native patterns can be adapted to embedded orchestration while preserving security, observability, and reproducibility requirements that are central to industrial cyber-physical platforms and to the ING-INF/05 research area.
\end{abstract}
