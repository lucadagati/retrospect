\section{Reviewer-Oriented Clarifications}
To facilitate peer review and eventual artifact inspection, the final camera-ready package should explicitly report the following items.
\begin{enumerate}[label=\arabic*)]
    \item exact software versions, commit hashes, and image tags used for the evaluated deployment;
    \item node and host hardware profile, including CPU, RAM, and operating system information;
    \item raw experiment scripts and the exact command sequence used for deployment and validation;
    \item representative failure cases and the rationale behind the adopted reconciliation mitigation;
    \item any deviations between the reviewed artifact and the final public replication package.
\end{enumerate}

Including these items does not change the platform itself, but it materially improves the manuscript's credibility and the ease with which reviewers can verify the scope of the claims.
